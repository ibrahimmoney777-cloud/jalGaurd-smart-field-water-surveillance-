# JalGuard — Smart Field Water Surveillance

A responsive static website for the JalGuard SIH 2026 project (SIH26252), built with HTML, CSS and vanilla JavaScript. It uses team-provided project assets and keeps the project's status clear: JalGuard is a proposed prototype under development, and its screening performance must be validated.

## Run locally

1. Extract this folder.
2. Open `index.html` in a modern browser.
3. For a local server, you can use VS Code Live Server or run `python -m http.server 8000` from this directory and open `http://localhost:8000`.

No build step or package installation is required.

## Main files

- `index.html` — page content and sections
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation, reveal animation, scroll progress and prototype image lightbox
- `assets/team/` — team photographs
- `assets/prototype/` — prototype reference images
- `assets/downloads/` — team presentation and case study documents

## Important project wording

- Microplastic imaging is described as preliminary/candidate screening; visual appearance alone cannot confirm polymer identity.
- The PFAS module is labelled proposed and requires a suitable sensing method, calibration and laboratory validation.
- The dashboard graphics are illustrative only and do not display live measurements.
